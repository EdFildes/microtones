# Micro Tones

## What is it?
A browser based app for making chords/drones composed of unusual musical intervals. The root note is adjustable.

5. Architecture / interesting technical decisions

This is where READMEs become genuinely valuable.

Even a few paragraphs here massively separates serious projects from tutorial clones.

Things worth explaining:

    how audio timing is handled

    why you chose Web Audio over HTML audio

    state management approach

    latency constraints

    how interval generation works

    how musical data is represented

    caching strategy

    why you avoided backend infrastructure

Example:

    Notes are scheduled using the Web Audio clock rather than setTimeout to avoid drift during rhythmic playback.

That single sentence already signals real understanding.
6. Setup instructions

This should be idiot-proof.

Example:

npm install
npm run dev

Also mention:

    required Node version

    env vars

    browser support

    whether autoplay permissions affect audio
