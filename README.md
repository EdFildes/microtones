# Interval explorer

## How it works

- Clicking each square plays a different musical note. 
- There is a "root note" which is set using the slider at the top of the screen.
- Each square is related to this root note by the mathematical ratio y:x. I.e. if the root note is 100hz and you click the square at y=3, x=2 then the resulting tone will be 100 * (3 / 2) which equals 150hz.
- Each octave contains the same hue of colour for each note but with darker tones at lower octaves and lighter tones at higher octaves.
